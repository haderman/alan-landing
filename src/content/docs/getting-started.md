Alan AI brings multiple AI chat agents into Visual Studio Code so you can work with an assistant without leaving your editor.

## Install Alan AI

Open the [Alan AI extension page](https://marketplace.visualstudio.com/items?itemName=haderman.alanai) in the Visual Studio Code Marketplace and select **Install**.

You can also install it from Visual Studio Code:

1. Open the Extensions view.
2. Search for `Alan AI`.
3. Select the extension published by Alan AI.
4. Select **Install**.

## Open Alan AI

After installation, open the Alan AI panel from the Visual Studio Code Activity Bar or the Command Palette.

If this is your first time using Alan AI, the extension will guide you through adding an OpenAI API key.

## Start a conversation

Choose an agent and send a message. You can ask Alan to explain code, suggest an implementation, review a change, or help you investigate an error.

For the best results, include the relevant file, error message, or goal in your prompt. Alan can then provide a more specific answer without requiring you to leave Visual Studio Code.
